# 💰 BudgetWise AI

## Personal Budget Analysis & Expense Prediction

### Data Analytics & AI Project

BudgetWise AI is a Data Analytics and Machine Learning project
designed to analyze personal budgeting data, identify spending
patterns, calculate savings, and predict total expenses.

## Objectives

- Analyze income and expenses
- Identify major spending categories
- Calculate savings
- Analyze spending patterns
- Visualize financial data
- Predict total expenses using Machine Learning
- Generate data-driven budgeting insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Model

The project uses Random Forest Regression to predict total
expenses based on income and different expense categories.

## Dataset

The project uses budgeting data containing income and multiple
expense categories such as:

- Rent
- Food
- Transport
- Shopping
- Entertainment
- Healthcare
- Education
- Bills
- Other expenses

## Project Workflow

Data Collection
→ Data Cleaning
→ Exploratory Data Analysis
→ Data Visualization
→ Feature Engineering
→ Machine Learning
→ Prediction
→ Budgeting Insights

## Project Files

- `BudgetWise_Budgeting.ipynb` - Complete project notebook
- `BudgetWise_Final_Results.csv` - Project results/data
- `requirements.txt` - Required Python libraries
- `README.md` - Project documentation
